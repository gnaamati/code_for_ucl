SUBROUTINES

read_file ( $file )
Reads data from a file into a string (doesn't chomp)
slurp( $file )
Parses the file and returns the lines as an array. Each line is chomped to remove "\n";
slurp_no_chomp( $file )
Same as slurp but doesn't chomp lines
shift_first( $file )
Shifts the first line of a file The file remains the same without the first line
file2hash ( $file )
Parses the lines of a file into a hash Each key gets a value of 1
file2hash_tab ( $file)
Parses the data into a hash with the keys and values tab delimited. Skips lines starting with #
hash2file_tab ($hash, $file)
Parses a hash into a file (tab delimited)
sub get_files_from_dir ( $dir )
Gets files from a directory and returns them in list format
line2hash ($header, $line)
Splits a line and parses it into the hash according to given headers
slurp_excel ($file)
Parses an Excel file and returns the data as a list of tab delimited lines
get_slice_adaptor ($reg_file, $species)
Create a slice adaptor according to the species and registry
get_gene_adaptor ($reg_file, $species)
Create a slice adaptor according to the species and registry
